Trainingsprüfung

Sie führen ein Prüfungsgespräch mit einem simulierten Prüfer. Ihre Antworten werden über das Mikrofon aufgenommen und automatisch transkribiert.

Der erste Start kann einige Minuten dauern, weil die Sprachmodelle geladen werden. Das Mikrofon funktioniert nur über localhost oder HTTPS.
